# Ponte English

Curso de inglês do A1 ao C1 (20 unidades, 120 palavras com imagem, 20 tópicos de gramática),
com áudio, 8 tipos de exercício, revisão automática e teste de nível.

Site 100% estático: não precisa instalar nada nem rodar build.

## Estrutura

```
index.html      página principal
css/style.css   visual (cores, fontes, layout)
js/course.js    conteúdo do curso (edite aqui para adicionar palavras e unidades)
js/app.js       funcionamento do app
```

## Testar no computador

Dê dois cliques em `index.html`. Ele abre no navegador.

## Publicar na Vercel (grátis)

1. Suba esta pasta para um repositório no GitHub.
2. Em vercel.com, faça login com o GitHub e clique em **Add New → Project**.
3. Escolha o repositório, deixe **Framework Preset = Other** e clique em **Deploy**.

O guia completo, passo a passo, está no documento que acompanha este projeto.
